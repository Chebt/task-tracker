A full-stack task tracker built to learn the stack from the ground up, 
not from a tutorial. Started with raw parameterized SQL, migrated to SQLAlchemy, 
then PostgreSQL. Auth is hand-rolled: hashed passwords, JWTs, and 
per-user data isolation verified end-to-end. 
Frontend is React (Vite) with full CRUD wired to a live backend 
— loading states, error banners, and persistence all tested, not assumed.
